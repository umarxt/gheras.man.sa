# منصة أسئلة مسار

منصة يسأل فيها المشاركون في برنامج مسار بلا أسماء، وتراجع الإدارة الأسئلة وتجيب عنها، ثم تظهر للجميع.
مبنية على واجهة غراس (`design-kit`) بهوية برنامج مسار، وتخزن كل شيء في قوقل شيتس عبر Google Apps Script (مجاني).

```
masar/
  public/            الموقع (ينشر على Netlify كما هو، بلا بناء)
    index.html       صفحة المشاركين: «اكتب سؤالك» و«أسئلة المشاركين»
    admin.html       لوحة الإدارة (برمز)
    config.js        رابط Apps Script والحدود
  apps-script/
    Code.gs          السكربت الذي يلصق في قوقل شيتس
```

## مسار السؤال

```
المشارك يكتب سؤالا  ←  «الأسئلة الجديدة» عند المدير المعتمد
                         ├─ حذف  ← لا يظهر لأحد
                         └─ اعتماد (مع إمكانية تعديل الصياغة)
                               ←  «الأسئلة المعتمدة» عند مدير الرد
                                     يكتب الرد ويضغط «إرسال»
                                        ←  يظهر السؤال مع الرد في «أسئلة المشاركين»
```

- **أسئلة المشاركين** فيها تبويبان: **الأحدث** (ما أجيب عنه خلال آخر ٢٤ ساعة) و**كل الأسئلة المجابة** (الأرشيف كاملا)، مع بحث.
- **الإدارة** برمزين مختلفين:
  - رمز **المدير المعتمد**: يرى الأسئلة الجديدة، ويعتمدها أو يحذفها، ويرى المعتمدة التي تنتظر الرد.
  - رمز **مدير الرد**: يرى الأسئلة المعتمدة فقط، ويكتب الرد ثم يرسله. تحفظ مسودة الرد في جهازه حتى يرسل.

## السرية

- لا اسم ولا تسجيل ولا رقم ولا بريد.
- الموقع يرسل السؤال بلا ملفات تعريف (cookies) وبلا Referrer، ولا يستخدم أي أداة تتبع أو إحصاء.
- Google Apps Script لا يعطي السكربت عنوان IP ولا هوية الزائر، والسكربت لا يحفظ إلا نص السؤال.
- وقت الوصول يحفظ مقربا لأقرب ١٠ دقائق، والمعرف عشوائي.
- صفحة المشاركين لا تحفظ في الجهاز أي مسودة أو أثر للسؤال.
- إن عدل المدير صياغة السؤال قبل اعتماده (لحذف اسم مثلا) يحفظ النص الأصلي في عمود خاص في الشيت، ولا يظهر للمشاركين.

## التركيب (مرة واحدة، نحو ١٠ دقائق)

### ١) قوقل شيتس + السكربت
1. أنشئ ملف Google Sheets جديدا.
2. **الإضافات (Extensions) ← Apps Script**، واحذف الموجود والصق `apps-script/Code.gs` كاملا.
3. في أعلى الملف غيّر `SUPERVISOR_CODE` و`RESPONDER_CODE`. ويمكنك وضع بريد في `NOTIFY_EMAIL` ليصلك تنبيه عند وصول سؤال جديد.
4. احفظ، واختر الدالة `setup` واضغط **Run**، ووافق على الصلاحيات. تنشأ ورقة **الأسئلة**.
5. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - انسخ الرابط (ينتهي بـ `/exec`).

### ٢) الموقع
1. الصق الرابط في `public/config.js` في `APPS_SCRIPT_URL`.
2. في Netlify: **Add new site ← Import from Git**، واختر هذا المستودع، واجعل **Base directory** = `masar`. (أو اسحب مجلد `masar/public` إلى Netlify Drop.)

> إذا عدلت `Code.gs` لاحقا: **Deploy ← Manage deployments ← تحرير ← Version: New version** ليبقى الرابط نفسه.

## الشيت
ورقة **الأسئلة** فيها: المعرف، وقت الوصول، السؤال، الحالة (جديد/معتمد/منشور/محذوف)، وقت الاعتماد، الرد، وقت النشر، ونص السؤال قبل التعديل.
الحذف لا يمسح الصف، بل يجعل حالته «محذوف» حتى يمكن الرجوع عنه من الشيت. ويمكن تعديل نص أي رد منشور من الشيت مباشرة (يظهر التعديل خلال دقيقة).

## التجربة محليا
```
cd masar/public && python3 -m http.server 8000
```
إذا كان `APPS_SCRIPT_URL` فارغا تعمل المنصة في **وضع المعاينة**: البيانات تحفظ في المتصفح فقط وفيها أمثلة، ورموز الإدارة التجريبية `1111` (المدير المعتمد) و`2222` (مدير الرد).
