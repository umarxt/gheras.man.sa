# منصة أسئلة مسار

منصة يسأل فيها المشاركون في برنامج مسار بلا أسماء، وتراجع الإدارة الأسئلة وتجيب عنها، ثم تظهر للجميع.
مبنية على واجهة غراس (`design-kit`) بهوية برنامج مسار، وتخزن كل شيء في قوقل شيتس عبر Google Apps Script (مجاني).

```
masar/
  public/            الموقع (ينشر على Netlify كما هو، بلا بناء)
    index.html       صفحة المشاركين: «اكتب سؤالك» و«أسئلة المشاركين»
    admin.html       لوحة الإدارة (برمز)
    config.js        رابط Apps Script والحدود
  apps-script/
    Code.gs          السكربت الذي يلصق في قوقل شيتس
```

## مسار السؤال

```
المشارك يكتب سؤاله ويختار: عام أو خاص  ←  يأخذ رمز متابعة (مثل ABCD-EFGH)
        ↓
يصل مباشرة إلى كل المشرفين (مقدمي الحقيبة)، بلا اعتماد إدارة
        ├─ سؤال عام:  «نشر للجميع مع الرد» (هذا إذن النشر)  ←  يظهر في «أسئلة المشاركين» باسم المشرف
        │             أو «رد خاص»  ←  يراه المشارك وحده
        ├─ سؤال خاص:  «رد خاص» فقط، ولا ينشر أبدا
        └─ «حذف»  ←  لا يظهر لأحد
المشارك يشوف الرد في «أسئلتي» برمز المتابعة (محفوظ في جهازه، ويقدر يضيفه في جهاز آخر)
```

- **أسئلة المشاركين** فيها ثلاثة تبويبات: **الأحدث** (آخر ٢٤ ساعة)، و**كل الأسئلة المجابة**، و**أسئلتي** (أسئلة المشارك وردودها، العامة والخاصة).
- إذا وصل رد جديد على سؤال من أسئلة المشارك، يظهر له إشعار عند فتح المنصة.
- **المشرفون:** لكل مشرف رمزه الخاص في ورقة **المشرفون** في الشيت (الاسم، الرمز، البريد اختياري، فعال). كل المشرفين يرون كل الأسئلة، واسم المشرف يظهر مع رده.
- في تبويب **تم الرد** يقدر المشرف **إلغاء النشر**: يرجع السؤال إلى «أسئلة جديدة» بنصه الأصلي، ويبقى الرد مسودة.

## السرية

- لا اسم ولا تسجيل ولا رقم ولا بريد.
- الموقع يرسل السؤال بلا ملفات تعريف (cookies) وبلا Referrer، ولا يستخدم أي أداة تتبع أو إحصاء.
- Google Apps Script لا يعطي السكربت عنوان IP ولا هوية الزائر.
- وقت الوصول يحفظ مقربا لأقرب ١٠ دقائق، والمعرف عشوائي.
- رمز المتابعة عشوائي، ولا يحفظ نصه في الشيت بل بصمته فقط (مع ملح سري في خصائص السكربت)، فحتى من يفتح الشيت لا يستطيع استعماله.
- الشيء الوحيد المحفوظ في جهاز المشارك رموز متابعة أسئلته، ويقدر يزيلها من «أسئلتي».

## التركيب (مرة واحدة، نحو ١٠ دقائق)

### ١) قوقل شيتس + السكربت
1. أنشئ ملف Google Sheets جديدا.
2. **الإضافات (Extensions) ← Apps Script**، واحذف الموجود والصق `apps-script/Code.gs` كاملا.
3. (اختياري) ضع بريدا في `NOTIFY_EMAIL` في أعلى الملف ليصلك تنبيه عند وصول سؤال جديد.
4. احفظ، واختر الدالة `setup` واضغط **Run**، ووافق على الصلاحيات. تنشأ ورقتا **الأسئلة** و**المشرفون**.
   في ورقة **المشرفون** اكتب صفا لكل مقدم حقيبة: الاسم (يظهر مع رده) والرمز الخاص به، وفعّل خانة **فعال**. لإيقاف مشرف ألغ تفعيل خانته.
   إذا كانت عندك ورقة أسئلة من النسخة السابقة، تنقل أسئلتها تلقائيا وتبقى القديمة باسم «الأسئلة (النسخة السابقة)».
5. **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - انسخ الرابط (ينتهي بـ `/exec`).

### ٢) الموقع
1. الصق الرابط في `public/config.js` في `APPS_SCRIPT_URL`.
2. في Netlify: **Add new site ← Import from Git**، واختر هذا المستودع، واجعل **Base directory** = `masar`. (أو اسحب مجلد `masar/public` إلى Netlify Drop.)

> إذا عدلت `Code.gs` لاحقا: **Deploy ← Manage deployments ← تحرير ← Version: New version** ليبقى الرابط نفسه.

## الشيت
ورقة **الأسئلة** فيها: المعرف، وقت الوصول، السؤال، النوع (عام/خاص)، الحالة (جديد/منشور/رد خاص/محذوف)، الرد، المشرف، وقت الرد، بصمة رمز المتابعة، ونص السؤال قبل التعديل.
ورقة **المشرفون** فيها: الاسم، الرمز، البريد (اختياري)، فعال.
الحذف لا يمسح الصف، بل يجعل حالته «محذوف» حتى يمكن الرجوع عنه من الشيت. ويمكن تعديل نص أي رد منشور من الشيت مباشرة (يظهر التعديل خلال دقيقة).

## التجربة محليا
```
cd masar/public && python3 -m http.server 8000
```
إذا كان `APPS_SCRIPT_URL` فارغا تعمل المنصة في **وضع المعاينة**: البيانات تحفظ في المتصفح فقط وفيها أمثلة، ورموز المشرفين التجريبية `1198` و`1996`.
