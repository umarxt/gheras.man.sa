# جوال أبو سعد ضايع — جمعية غراس

موقع ثابت (بدون خادم أو قاعدة بيانات). يحاكي جوال آيفون مفقود لمدير الجمعية «أبو سعد»: شاشة قفل، رسائل واتساب ونصية، بريد، مكالمات، منبّهات، ملاحظات، صور، إعدادات… وتصل أحداث جديدة تلقائياً كأن أحداً يتصل به.

```
index.html     الشكل والحركات
app.js         المنطق (القصص الحيّة، التنقل، التطبيقات)
content.json   كل المحتوى: المحادثات، الرسائل، القصص (arcs)، الملاحظات، الصور، الاتصال
assets/        الشعار والخط
```

## التجربة محليا
```
cd lost-phone && python3 -m http.server 8765
```
افتح `http://localhost:8765` (أو `/#unlock` لتخطي شاشة القفل).

## النشر
انشر مجلد `lost-phone` كما هو على Netlify (Base directory = `lost-phone`) أو أي استضافة ثابتة.

## تعديل المحتوى
- بيانات التواصل في `content.json` ← `config` (الهاتف، الموقع، البريد، X).
- كل قصة حيّة في `arcs`: خطوات من نوع `wa` أو `sms` أو `mail` أو `call` أو `alarm` أو `cal`.
- حالة الزائر تُحفظ في `localStorage` بالمفتاح `gheras-phone-v1`.
