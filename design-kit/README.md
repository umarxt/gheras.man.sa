# حزمة واجهة غراس

حزمة الهوية والحركات المستخرجة من موقع «نموذج تقييم البرامج القائمة»، لإعادة استخدامها في مواقع جديدة.

- `PROMPT.md`: البرومت الذي تلصقه في محادثة جديدة.
- `demo.html`: صفحة تعرض كل المكونات. افتحها محليا (`python3 -m http.server` داخل المجلد) وادخل بالرمز `1234`.
- `kit.css` و`kit.js`: التصميم والحركات.
- `assets/`: الشعارات والأيقونات والباترن والخط.
